Diseño Web

CSS


CSS (siglas en inglés de Cascading Style Sheets, traducido como Hojas de Estilo en Cascada) es el
lenguaje informático utilizado para definir y personalizar la apariencia visual de un documento
estructurado en HTML o XML. Mientras que HTML se encarga de crear el contenido y el esqueleto de una
página web (como textos, botones y enlaces), CSS le da color, tipografía, márgenes, fondos y se asegura de
que todo luzca ordenado y moderno.

HTML

HTML es el HyperText Markup Language (Lenguaje de Marcado de Hipertexto), la columna vertebral y el
esqueleto de cualquier sitio web. No se trata de un lenguaje de programación, sino de un lenguaje de
marcado basado en etiquetas que define la estructura y el contenido básico de una página web (como textos,
imágenes y enlaces), permitiendo que los navegadores la interpreten de forma estandarizada.

JAVASCRIPT

JavaScript (JS) es el lenguaje de programación oficial de la web. A diferencia de HTML (que define la
estructura) y CSS (que define el diseño), JavaScript se encarga de dar interactividad, lógica y dinamismo
a las páginas web, permitiendo que respondan a las acciones de los usuarios en tiempo real sin necesidad
de recargar la página.


¿para que sirve el diseño web?


El diseño web sirve para planificar, crear y organizar sitios en internet de manera que resulten atractivos, fáciles de usar y útiles para los usuarios.

Funciones

  • principalesCrear una buena imagen: Muestra la identidad de una empresa y transmite confianza desde el primer momento.

  • Facilitar la navegación: Permite que las personas encuentren la información rápidamente y sin problemas.

  • Adaptarse a dispositivos: Logra que la página se vea bien tanto en computadoras como en teléfonos celulares y tabletas.

  • Mejorar las ventas: Ayuda a que más visitantes realicen compras o contraten un servicio.

  • Ayudar en buscadores: Ordena el contenido para que Google y otros buscadores puedan leerlo con facilidad y mostrarlo a más personas.
